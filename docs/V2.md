# Версия 2: что меняется (на согласовании)

Решения из обсуждения. Источник агентов — только манифесты спонсоров, готовых агентов рынка не берём.

## Агент

**Визитка в контракте, открыто:**

| Поле | Зачем |
|---|---|
| `skills` | что знает и умеет, до 500 символов. По ней выбирают команду, её видят все |
| `rate` | ставка спонсора за участие в задаче, USDC. Включает его инференс и наценку за знания |
| `max_cost` | потолок инференса за одну задачу (как сейчас) |
| `url`, `hash`, `size` | где лежит зашифрованный файл агента, его sha256 и размер |
| `status` | ждёт ревью, работает, отключён |

**Файл агента, зашифрован ключом раннера, лежит где угодно, до 10 MB:**
промпт, знания и опыт любого объёма, модель, инструменты (`none` или `search`), лимит шагов.
Хранилище выбирает спонсор. Подменить файл нельзя (хэш), прочитать тоже (шифрование).

## Контракт

Убирается: хранение манифестов, их лимит и метод чтения.

| Шаг | Что делает |
|---|---|
| Регистрация (`ft_transfer_call`) | спонсор присылает визитку и депозит. Плата за ревью = база + цена за мегабайт × `size`, уходит оператору; остаток на баланс; статус «ждёт ревью» |
| Пополнение, выручка, ревью, удержание, расчёт, закрытие, вывод | как сейчас |
| Удержание (`assign`) | до 32 агентов в задаче (техническая граница по газу) |
| Расчёт (`finish`) | стоимость округляется вверх до шага 0.01 USDC: скрытый канал через стоимость сужается до пары бит |

## Раннер

**Ревью агента:**
1. Скачать файл один раз, параллельно с другими, с таймаутом и SSRF-фильтром; размер не больше заявленного.
2. Проверить хэш, расшифровать, проверить схему.
3. Сохранить зашифрованную копию и индекс знаний на зашифрованный диск TEE. После этого хостинг спонсора не нужен.
4. Модель-ревьюер видит промпт, навыки, инструменты и выборку знаний, а не всё целиком.
5. Три неудачные загрузки подряд — отказ.

**Задача:**

| Шаг | Кто | Что видит и делает |
|---|---|---|
| Проверка задачи | модель протокола | бриф и сообщения заказчика |
| Отбор кандидатов | код | эмбеддинги задачи и открытых навыков: 20 ближайших. Навыки не могут «уговорить» этот шаг |
| Выбор команды | модель протокола | задача и визитки кандидатов. Число агентов не задано: сумма ставок не больше бюджета. Каждому пишет вопрос, в котором только нужное ему из брифа |
| Материалы | протокол | если задаче нужны свежие публичные данные, протокол сам ищет и скачивает страницы и раздаёт их текст агентам |
| Ответы | агенты | свой промпт и знания, ближайшие куски базы, свой вопрос, материалы. Сети нет. Инструмент `search` (если включён): поиск у фиксированного поисковика и открытие только адресов из выдачи |
| Сборка | модель протокола | ответы по номерам; каждое утверждение помечено номером источника, пометки убираются перед сдачей |
| Оценка вклада | отдельный вызов модели протокола | по каждому агенту: ответил на свой вопрос (0–4), верно и без противоречий (0–3), вошёл в ответ (0–3, механически по пометкам). Нарушение — 0 |
| Деньги | раннер → контракт | вес = ставка × вклад; стоимость округлена; выручка по весам |

**Цена для заказчика:** сумма ставок команды + накладные протокола + комиссия владельца + 5% Agent Market.
- Задача с доски: рой ставит эту цену в ставке.
- Мгновенный найм по тарифу: команда подбирается под бюджет.

**Доработки:**
- В цену входят 2 доработки в рамках исходной задачи; это условие записано в описании роя на рынке.
- Модель протокола сверяет каждое замечание с брифом.
- Замечание вне задачи или сверх лимита: ответ в переписке и повторная сдача прошлого ответа с пометкой.
- Решение арбитра «переделать» выполняется всегда.

**Безопасность:**
- скачивание и разбор чужого HTML в отдельном процессе с лимитом времени и памяти;
- в логах только коды ошибок;
- тесты SSRF на хитрые адреса.
