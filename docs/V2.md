# Версия 2

> Рой — это способ сложить закрытые знания разных владельцев без доверия друг к другу.

Источник агентов — только спонсоры, готовых агентов рынка не берём. Мы для заказчика — генподрядчик:
он видит только рой, а отвечаем перед ним и перед Agent Market мы.

## Гарантии по построению

Модель можно обмануть, поэтому деньги и данные не зависят от того, распознала ли она злого спонсора.

1. **Изоляция.** Агент видит только свой вопрос и материалы от протокола; его ответ уходит только протоколу. Других агентов и сети он не видит.
2. **Оплата по договорённости.** Ставка агента фиксируется в контракте при выборе команды; выплата — 0 или ровно ставка. Недоплаченное уходит протоколу, а не соседям, поэтому топить соседа невыгодно.
3. **Изолированная оценка.** «Сделал / не сделал / нарушил» решает отдельный вызов, который видит только задачу, вопрос этого агента и его ответ.
4. **Ограниченные потери.** Спонсор рискует только своим балансом: потолок за задачу плюс плата за аудит.
5. **Расходы платит тот, кто их вызвал.** Инференс агента — с его баланса; аудит — платой по объёму; работа протокола — из цены задачи.
6. **Мы ничего не исполняем.** Загруженное — только текст; агенты не запускают код и не действуют во внешнем мире; результат проходит выходной фильтр.

## Агент

**Визитка, открыто в контракте:** навыки (до 500 символов, только простой текст), ставка за участие, потолок инференса
за задачу, хэш собранного агента, статус.

**Материалы, закрыто:** описание экспертизы, методика, знания любого объёма (до 10 MB), модель из списка.
Системный промпт не пишет спонсор: агент собирается по **нашему шаблону**, а материалы спонсора входят в него как
справочные данные, а не как команды. Спонсор приносит знания, а не инструкции.

## Регистрация

```
спонсор (UI или CLI) ── материалы, зашифрованные в браузере ключом раннера из аттестации ──► раннер в TEE
  1. расшифровать
  2. принять только текст и PDF; конвертировать в простой текст в отдельном процессе с лимитами; оригинал выбросить
  3. аудит всего: скрытые символы и инструкции, вредоносный код, персональные данные (privacy-filter), вредное содержание
  4. собрать агента по шаблону, проиндексировать знания
  5. запечатать ключом раннера, хранить у протокола
контракт: визитка + хэш собранного агента; review → «работает» или отказ
```

- Материалы после этого недоступны никому, включая нас. Изменить их можно только новой подачей и новым аудитом.
- UI шифрует на стороне спонсора; код UI отдаётся из TEE. Для недоверчивых остаётся CLI.
- Люди проверяют только визитку. Знания проверяются автоматически внутри TEE.
- Плата за аудит = база + цена за мегабайт.

## Контракт

| Метод | Что делает |
|---|---|
| регистрация (`ft_transfer_call`) | визитка + депозит; плата за аудит оператору; статус «ждёт аудита» |
| `review` | раннер: «работает» или отказ, по хэшу собранного агента |
| `assign` | удерживает потолок у каждого и **фиксирует ставку** в задаче; до 32 агентов |
| `finish` | стоимость инференса оператору (округлена вверх до 0.01 USDC), остаток агенту; выплата каждому — **0 или его ставка** |
| выручка | каждому его выплата; если пришло меньше суммы выплат — пропорционально; остаток — протоколу |
| пополнение, закрытие по таймауту, вывод, настройки | как сейчас |

Хранение манифестов в контракте убирается.

## Задача

| Шаг | Кто | Что видит и делает |
|---|---|---|
| проверка задачи | модель протокола | бриф и сообщения заказчика |
| кандидаты | код | эмбеддинги задачи и открытых навыков: 20 ближайших |
| команда | модель протокола | задача и визитки кандидатов; сумма ставок не больше бюджета; каждому вопрос только с нужной ему частью брифа |
| материалы | протокол | если нужны свежие публичные данные, протокол сам ищет и скачивает страницы |
| ответы | агенты | шаблон + свои знания (ближайшие куски) + свой вопрос + материалы. Ни сети, ни инструментов |
| сборка | модель протокола | ответы по номерам; утверждения помечены источником; пометки убираются перед сдачей |
| оценка | отдельный вызов на каждого агента | только его вопрос и ответ: сделал / не сделал / нарушил |
| выходной фильтр | код + модель протокола | см. ниже |
| расчёт | раннер → контракт | выплаты 0 или ставка; стоимость округлена |

Вклад по пометкам источников идёт в репутацию (кого выбирать в будущем), а не в деньги.

## Выходной фильтр

| Что | Как |
|---|---|
| Markdown | без HTML, скриптов, iframe |
| ссылки | только на адреса из источников и материалов; остальные — обычный текст |
| картинки | внешние удаляются (трекеры) |
| невидимые символы, скрытые инструкции для AI заказчика | удаляются |
| файлы | только разрешённые типы; картинки пересобираются без метаданных |
| код | статическая проверка (скачать и запустить, `eval`, обфускация, скрытая сеть, кража ключей, майнеры, подозрительные зависимости) + ревью моделью; пометка «не запускался, проверьте» |
| содержание | источник у каждого утверждения; важное перепроверено вторым агентом; юридическое, медицинское, финансовое помечено |

Какой агент дал какое утверждение, раннер запоминает: если вред обнаружится в споре, виновный известен.

## Деньги

- **Цена для заказчика** = сумма ставок команды + накладные протокола + комиссия владельца + 5% Agent Market.
- **Задача с доски:** рой ставит эту цену. **Мгновенный найм по тарифу:** команда подбирается под бюджет.
- **NEAR AI** — один аккаунт оператора. Спонсору нужен только USDC; стоимость инференса агента оплачивается из его удержания.

## Доработки

- В цену входят 2 доработки в рамках исходной задачи; это записано в описании роя на рынке.
- Модель протокола сверяет замечание с брифом. Вне задачи или сверх лимита — ответ в переписке и повторная сдача прошлого ответа.
- Решение арбитра «переделать» выполняется всегда.
- Агенты на доработке получают замечания, прошлый ответ видит только сборщик.

## На согласовании

- **Уровни доверия:** новичок (недорогие задачи, всегда с перепроверкой, лимит заработка), проверенный (история без нарушений), подтверждённый (личность + депозит, доступ к чувствительным задачам).
- **Поисковик для материалов:** Brave Search API по умолчанию.
- **Размер накладных:** снять с первых живых задач.
