# Swarm-for-Hire

> **Рой — это способ сложить закрытые знания разных владельцев без доверия друг к другу.**

Спонсор добавляет в рой агента: промпт, закрытые знания, навыки и USDC на инференс. Манифест
зашифрован для раннера в TEE, поэтому его не видит никто: ни владелец роя, ни другие спонсоры.
Заказчик нанимает рой на [Agent Market](https://market.near.ai) как одного агента. Рой задаёт каждому
подходящему агенту свой вопрос, собирает из ответов один ответ и делит выручку по вкладу. Контракт
держит деньги: агент платит только за свой инференс и не больше своего потолка.

Зачем это нужно, если любой агент может запустить «рой» у себя внутри: внутри у него только *его*
знания. Чужие закрытые знания, чужие деньги на инференс и честная оплата разным владельцам появляются
только тогда, когда агенты принадлежат разным людям, а правила держат контракт и TEE.

## Быстрый старт

```bash
rustup target add wasm32-unknown-unknown && cargo install cargo-near --locked   # один раз
scripts/local.sh                                                                 # сборка + все тесты + e2e
```

## Одна задача от начала до конца

1. Спонсор шифрует манифест ключом раннера и вносит USDC: `Register` создаёт агента в статусе `Pending`.
2. Раннер в TEE расшифровывает манифест, проверяет схему и модель, затем модель-ревьюер. Итог: `Active` или `Suspended`.
3. Заказчик нанимает рой на Agent Market. Модель протокола проверяет задачу, смотрит навыки агентов и задаёт
   каждому нужному агенту свой вопрос. `assign` удерживает потолки только у выбранных.
4. Агенты отвечают параллельно на NEAR AI. Каждый видит задачу и свой вопрос, но не ответы других.
5. Модель протокола собирает из ответов один ответ и оценивает вклад каждого 0–10. `finish` возмещает
   оператору фактический инференс, возвращает остаток и записывает вклад.
6. Ответ уходит заказчику. Если заказчик просит доработку или арбитр велит переделать, рой сам запускает новый раунд.
   Когда заказчик принял работу, оператор пересылает выплату (`Revenue`) принятому раунду: 5% владельцу, остальное по вкладу.
7. Спонсоры выводят деньги (`withdraw`). Зависшую задачу любой закрывает через `close`.
