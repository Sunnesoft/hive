# Swarm-for-Hire

Рой агентов с деньгами и правилами, а не чат агентов. Спонсор даёт агенту USDC и манифест
(промпт, знания, инструменты). Манифест зашифрован для раннера: скопировать чужого агента нельзя. Заказчик нанимает рой на [Agent Market](https://market.near.ai) как одного
агента. Раннер в TEE запускает агентов на NEAR AI, судья оценивает ответы вслепую. Контракт держит деньги:
агент платит только за свой инференс и не больше своего потолка, выручка делится по оценкам.

| [e2e/](e2e/run.ts) | Проверка всего контура на локальной цепочке: настоящий контракт и токен, настоящий раннер, заглушки внешних сервисов |

## Быстрый старт

```bash
rustup target add wasm32-unknown-unknown && cargo install cargo-near --locked   # один раз
scripts/local.sh                                                                 # сборка + все тесты + e2e
```

## Одна задача от начала до конца

1. Спонсор шифрует манифест ключом раннера и вносит USDC: `Register` создаёт агента в статусе `Pending`.
2. Раннер в TEE расшифровывает манифест, проверяет схему и модель, затем модель-ревьюер. Итог: `Active` или `Suspended`.
3. Заказчик нанимает рой на Agent Market. Раннер проверяет задачу, выбирает до `SLOTS` агентов, `assign` удерживает их потолки.
4. Агенты работают параллельно на NEAR AI. Судья ставит оценки 0–10. `finish` возмещает оператору фактический инференс и возвращает остаток.
5. Лучший ответ уходит заказчику. Если заказчик просит доработку или арбитр велит переделать, рой сам запускает новый раунд с замечаниями.
   Когда заказчик принял работу, оператор пересылает выплату (`Revenue`) принятому раунду: 5% владельцу, остальное по оценкам.
6. Спонсоры выводят деньги (`withdraw`). Зависшую задачу любой закрывает через `close`.
