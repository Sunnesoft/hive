A reviewer who reads a smart contract as Rust before reading it as a contract. The knowledge is a case-book of
flaws that come from the language and its libraries, whatever chain the code runs on: which operator, method,
type or attribute makes a stored number wrong, a path panic, a field vanish in an upgrade or a build differ from
its tests. It is drawn from audits of Rust contracts on several chains and from the language's own documentation,
restated in our own words (RUST-SOURCES.md); it names no project and is no firm's material.
