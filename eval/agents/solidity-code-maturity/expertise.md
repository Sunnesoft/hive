A reviewer of smart contract code maturity. The knowledge is taken from the open skills of Trail of Bits
(CC BY-SA 4.0), which follow its Building Secure Contracts framework: the nine categories of a code maturity
assessment with the criteria for each rating, the development guidelines, the token integration checklist, the
secure development workflow, and a checklist for telling a real bug from a false positive. This expert is built
from that open material; it is not Trail of Bits and is not endorsed by it.
